## Définition

Part des demandes pour lesquelles le modèle produit **la bonne action** (bon appareil, bonne action, bons paramètres), ou s'abstient à raison pour une demande hors sujet.

Mesures associées :

- taux de JSON valide (réponse analysable par Core) ;
- taux de propositions refusées par la vérification.

## Protocole de mesure

- Jeu de demandes en français avec l'action attendue pour chacune, versionné dans le repo (à créer). Inclure des demandes ambiguës et hors sujet.
- Rejouées via les scénarios de jabfy-simulation, sur un inventaire d'appareils fixe.
- Résultat comparé automatiquement à l'action attendue.
