## Preuve d'antériorité du code

Pour pouvoir prouver la date de création du logiciel :

| Moyen | Principe | Fait le | Référence |
|---|---|---|---|
| Enveloppe e-Soleau (INPI) | Dépôt daté d'un fichier décrivant ou contenant la création | | |
| Dépôt APP | Dépôt du code source auprès de l'Agence pour la protection des programmes | | |

L'historique Git daté sur GitHub est un indice utile, mais pas une preuve aussi solide qu'un dépôt auprès d'un tiers.

## Brevet

En Europe, un logiciel « en tant que tel » n'est pas brevetable. Le code est protégé par le droit d'auteur ; la marque protège le nom.
