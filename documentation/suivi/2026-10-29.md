## Blocages

1. **Deux lignes d'intégration** : le bus embarqué dans la simulation (V0.0.1) ou dans Core (branche `core-12`) ? À décider avant de fusionner la V0.0.1 sur `main`.
2. **Trois versions de l'API de Core** (`/act`, `/simulation/propose`, `/prompt`) : choisir le contrat cible.
3. **La CI de jabfy-simulation est toujours rouge** : c'est un workflow Node sur un projet Python, donc aucune PR n'y est réellement testée.
4. **Fin de l'essai GitBook début novembre** : les liens de partage privés sont une fonction payante. Il faut demander l'offre Community (gratuite pour les groupes d'étudiants) ou accepter un site public.
