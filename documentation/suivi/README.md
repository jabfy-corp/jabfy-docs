# Suivi du projet

## Organisation

- Chaque **action** décidée en RDV devient une **issue** GitHub, dans le repo concerné.
- Chaque **jalon** est une **milestone** GitHub, voir [Roadmap et jalons](../projet/roadmap.md).
- Issues et milestones sont regroupées dans le **GitHub Project** de l'organisation.
- Le tableau d'actions d'un compte-rendu pointe vers les issues (`jabfy-core#12`) : l'avancement se suit dans GitHub, sans recopier les statuts à la main.
